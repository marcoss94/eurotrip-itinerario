# Europa en familia

Itinerario móvil alojado en GitHub Pages. Incluye enlaces a Google Maps, marcas con fecha y hora, notas y respaldo/importación del progreso.

El contenido y el PDF están cifrados con AES-256-GCM antes de subirlos. La clave viaja en el fragmento del enlace compartido y no se incluye en el repositorio ni se envía al servidor. Quien tenga el enlace completo puede abrirlo. No publiques la clave en issues, commits o este archivo.

El progreso se guarda en localStorage del dispositivo y navegador; no se sincroniza entre personas. Para trasladarlo, usa Más → Exportar respaldo e Importar respaldo.

Abre el enlace con conexión la primera vez. El navegador puede conservar una copia cifrada para posteriores consultas sin conexión. Google Maps y las fuentes externas requieren internet.

Las fuentes de autoría y la clave se conservan fuera del repositorio, en el espacio de trabajo del propietario. Para actualizar, reconstruir el HTML y ejecutar el empaquetador local; conservar la misma clave y los identificadores de actividades.

Publicación: rama `main`, carpeta raíz, GitHub Pages. No requiere servidor ni dependencias externas.
